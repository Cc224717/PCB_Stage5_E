【上线口径（重要，写进系统"模型信息"与答辩口径）】
1. 默认上线模型 = models/high_accuracy/best.pt
   即 YOLOv8n-P2-CBAM-light（P3点位），391.7万参数，8.21MB。
   与论文部署表（comparison.csv）完全同一权重，勿混用其他版本。
2. 轻量对照 = models/lightweight_baseline/best.pt（P2-only，292.7万，6.31MB），
   用于界面"模型切换"功能展示精度/速度差异。
3. 跨产线微调模型 = models/cross_line_finetune/best.pt，imgsz=640，
   类别映射见同目录 data.yaml，用于泛化演示（可选）。
4. 推理默认超参：imgsz=1024（主模型）/ 640（cross_line）、conf=0.25、iou=0.7。
   与论文 benchmark 对齐时用 conf=0.001。

【环境】
- requirements-lock.txt 有锁定版本；GPU 路径需 torch+cu124 + TensorRT。
- best.engine 与 RTX 4060 Laptop + CUDA 12.4 绑定，换机器必须用
  best.onnx 重新导出（D 的部署环境说明.md 有导出命令）。
- 纯 CPU 也能跑 PyTorch/ONNX 路径，只是 FPS 低，开发期够用。

【加载高精度模型必须先注册 CBAM】（否则报 KeyError: 'CBAM'）
    import sys
    from pathlib import Path
    from ultralytics import YOLO
    from ultralytics.nn import tasks
    pkg = Path(__file__).resolve().parent
    sys.path.insert(0, str(pkg / "python"))
    from cbam_module import CBAM
    tasks.CBAM = CBAM
    model = YOLO(str(pkg / "models/high_accuracy/best.pt"))

【已知坑（别踩）】
1. ONNX Runtime 直接 CUDA 绑定曾报 "no data transfer registered" 错误
   （见 benchmark/comparison.csv error 列），D 的结论是走 ultralytics
   封装或 CPUExecutionProvider 稳；engine 路径最稳。
2. stage3_stability 里 seed0 有个 28MB 旧权重，属历史异常，不要用。
3. batch_detect_before_*.py 是 C 的开发历史版本，仅作参考，以
   batch_detect.py 为准。

【验收清单（答辩必需截图，照 K.record 06_system_demo 标准）】

□ 结果保存：标注图 + json/csv 可导出
